AGRISENSE AI – SMART FARMING ASSISTANT
All-in-One Standalone Application & Source Package
========================================================================

PROJECT PURPOSE:
AgriSense AI is an AI-powered precision farming assistant for farmers.
It combines field IoT sensors (soil moisture, temperature, humidity),
weather forecasting, crop growth stages, and plant leaf screening
to provide simple, actionable recommendations.

HOW TO RUN:

METHOD 1: Instant 1-Click Launch (No Node.js or Setup Required!)
------------------------------------------------------------------------
Simply double-click:
  run_app.bat
OR double-click:
  index.html
The application will open immediately in Google Chrome, Microsoft Edge,
or your default web browser with 100% full functionality, charts,
interactive simulations, and all 12 pages!

METHOD 2: Development Server (Vite + TypeScript)
------------------------------------------------------------------------
1. Open PowerShell or Command Prompt in the root project folder:
   cd "c:\Users\lenovo\Documents\agro vision"
2. Start the development server:
   npm run dev
3. Open your browser at:
   http://localhost:3000

KEY PAGES INCLUDED:
1. Landing Page (System flow: Sensors -> AI Engine -> Advice -> Farmer)
2. Login / Sign Up Page (With "Continue with Demo" 1-click button)
3. Farm Setup Page (Farmer name, crop, growth stage, acreage, zones)
4. Main Dashboard (Farm health, sensor cards, zone cards, 24h/7d/30d charts)
5. Weather Page (Current conditions, 5-day forecast, rain risk advisory)
6. AI Farm Assistant Page (Water stress, over-irrigation, disease rules)
7. Crop Health Page (Foliage image upload, 4 sample leaves, screening AI)
8. Alerts Page (Critical/Warning/Info filters, simulation trigger)
9. Farm Zones Page (Topographic plot matrix, valve actuation)
10. Sensor Monitoring Page (ESP32 Node 1 & 2 health, live MQTT JSON stream)
11. Farm History Page (Statistical compliance table, audit trail)
12. Settings Page (Farmer profile, language options, units)

DEMONSTRATION FEATURES FOR SIH / EXAM:
- Click "Simulate Sensor" to show live sensor variations & dynamic AI reaction!
- Click "Simulate Alert" to show instant threshold incident warnings!
- Click "Load Demo" to reset to standard Green Valley Farm demo state!
- Try sample leaf images in "Crop Health" to demonstrate automated screening!
